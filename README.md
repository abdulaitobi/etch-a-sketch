# Etch a sketch

Sketch app that uses a mouse hover event to draw on a canvas.

![enter image description here](https://github.com/abdulaitobi/etch-a-sketch/blob/main/Etch%20a%20sketch%20Screenshot.png?raw=true)

## Features

- Set the size of the canvas to a max of 64x64
- Uses mouse hover event to draw over canvas
- Restore canvas to empty

## How to run
You can access Etch a Sketch through this link: https://abdulaitobi.github.io/etch-a-sketch/
